# 🔎 Nmap Network Enumeration

## Objective

Learn how to perform network reconnaissance and identify
open ports, running services, and service versions on an
authorized laboratory machine.

---

## 🛠️ Tool Used

- Nmap
- Kali Linux

---

## 📚 Concepts Learned

### IP Address

An IP address identifies a device/host on a network.

### Port

A port identifies a network service that is available on a host.

For example:

- Port 22 → SSH
- Port 80 → HTTP
- Port 443 → HTTPS

### TCP

TCP is a connection-oriented protocol.
